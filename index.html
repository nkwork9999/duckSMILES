duckSMILES

分子形式、記述子、指紋、構造検索、統計をDuckDB内で扱うネイティブ拡張。

利用ガイドSQL リファレンス

クイックスタート

INSTALL ducksmiles FROM community;
LOAD ducksmiles;
SELECT mol_formula('CCO'), mol_weight('CCO');

機能ガイド

分子形式と記述子SMILES、InChI、MOL/SDF、指紋、記述子と構造操作の使い方を検索できます。質量と分子グラフ同位体、分子式、質量照合と関係データへの展開を扱います。統計・機械学習回帰、分類、分散分析、実験計画と信頼性の各機能を掲載しています。材料組成と液体粘度材料の組成と測定物性を扱う関数、単位、計算条件を確認できます。
