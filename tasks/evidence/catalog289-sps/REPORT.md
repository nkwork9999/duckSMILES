**RDKitとの完全な数値互換ではありません。** 標準217定義のうち215項目は
固定版RDKit 2026.03.6の数値を基準とし、`Ipc` / `AvgIpc` の2項目は同じ数式を
整数の特性多項式で安定化しています。この2項目は固定RDKitの数値と
**5,723入力で差があります**。その比較も別の失敗ゲートとして公開しています。
CSV列名は `Ipc_stable` / `AvgIpc_stable`。RDKitで学習したモデルとの互換性は
この2列を区別して扱ってください。

追加50項目は、監査した登録済み標準APIとの重複がない既存のグラフ記述子です。
新しい科学的指標を発明したという主張はありません。実務用途・数式は
[定義](../../descriptors/extra50-definitions.json)、[標準API監査](../../descriptors/extra50-builtin-audit.json)にあります。

## 精度と入力範囲

[10万件の全結果](v42-full100k/comparison.json)と
[固定RDKitのIpc数値との差](v42-full100k/pinned-information-differences.jsonl.gz)。
各入力位置を一度ずつ検証し、ネイティブ側の受理結果による選別はしていません。
許容差を緩めていません。215標準・24プロファイルは固定RDKitの定義、
追加50は独立したNumPyによる密行列・数式、安定版2項目の係数は
python-flint 0.9.0 / FLINT 3.6.0を基準にしました。参照実装とネイティブ実装は別です。
未定義値は `null`、CSVでは空欄として照合し、ゼロに置き換えていません。
これは計算定義の検証で、実測物性や予測モデルの性能評価ではありません。

準備処理は640原子・1,280結合・4,096バイトまで。別の接続図APIは256原子・512結合のままです。
この集団で未対応0件であり、任意のSMILES表記・任意サイズをすべて扱えるという意味ではありません。

残っていた複数金属への配位結合5入力に対応しました。元の5件と順序変更などを含む
158入力は全291項目・分子式が一致。小さな非立体・括弧原子・単結合集団向けの
正準順位処理は、ランダムな生グラフを含む423順位ベクトルで固定RDKitと一致しました。
ランダムグラフは順位処理だけの試験で、化学的に有効な入力とはみなしていません。
非四面体の2入力は、唯一の変換先を初期順位から証明できる場合に限定し、元の立体タグを残します。
一般的な完全正準化の実装という主張はありません。

Rust release workspace: **808 passed / 0 failed / 2 ignored / 警告0**。
[実行結果](v42-workspace.json)、[ログ](v42-workspace-green.log)、

## 検証後の説明情報の確定

最終点検で、APIカタログに検証前の注記が残っていたため、`verification` を現行の
検証結果へ更新し、追加50項目に個別の `practical_use` を追加しました。
数式、適用範囲、ID、順序、表示桁、単位、許容差は変えていません。
凍結した検証時ソースと比べ、計算用Rustソース70ファイルとコンパイルされる
`SPECS` 定義部分がバイト一致することを確認しています。変えたRust資産は
`CATALOG_JSON` の説明情報だけです。

新しく生成したバイナリでも、元の1,000件＋金属錯体5件＋最大598原子入力の
1,006入力で全291値・状態・分子式が凍結版と完全一致しました。

最終アプリは、それと同一の計算実装を持つ説明情報更新版を組み込みました。
Simulator／実機向けビルドが成功し、日本語iPadの通常起動・保存6件の保持・再利用も確認済みです。
数値計算が変わらないため、キャッシュの計算版は42のままです。
